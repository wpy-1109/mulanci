# 王培宇 · 个人简历项目

用版本化方式管理简历：归档基线 → HR 结构化访谈采集信息 → 迭代新版。

## 目录

```
resumes/
  archive/          # 按日期归档的历史版本（PDF + Markdown）
  draft/            # 改稿中的版本
docs/
  简历更新计划.md    # 总体计划与里程碑
  interview-notes/  # 分轮访谈记录
```

## 当前基线
