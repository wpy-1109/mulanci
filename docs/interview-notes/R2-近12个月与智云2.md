### 工作模块（候选人自述，已归纳为三条主线）

1. **Bad case → 自动补知识**  
   针对未命中 / 未拦截的 bad case，自动回补与再注入原有知识，形成知识迭代。

2. **工具与 Skills**  
   为开发者侧接入 **7–8 个新工具**；将复杂场景沉淀为 **Skills**，再用于排查 / 调研类任务。

3. **Agent 平台替换与提效**  
   基于新 Agent 平台，用 Agent 替换原有多套 agent 实现；效率约 **翻倍**。  
   短周期能做成的关键原因：用 Agent 替代手工搭 agent，并实现**粗闭环的自动化/自运行**（原文：liberalization of the rough loop）。
