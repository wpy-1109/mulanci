## 原问题与回答

1. **更新目的**：主要跳槽外投。  
2. **主投岗位**：知识工程师，或 AI Agent 应用相关。  
3. **备选**：可接受 2–3 个相近岗位；清楚自身主背景是技术内容，希望在简历中「呈现」这条能力线，同时纠正目前「看起来太偏非技术内容」的问题。  
4. **公司类型**：优先大厂。  
5. **城市**：杭州。  
6. **薪资**：不写。  
7. **到岗时间**：不写。  
8. **突出标签（归纳）**：AI Agent 应用落地、知识工程、客户自助链路（智云 2）、技术内容底盘；管理弱化。
